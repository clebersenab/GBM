Perguntas frequentes

Para que idade é o GBM?

De 3 a 8 anos. Os textos são curtos e as ilustrações fazem boa parte do trabalho. Para os menores, a ideia é o adulto ler em voz alta. Os maiores podem acompanhar e ler trechos sozinhos.

As histórias são resumos dos clássicos?

Não. São histórias novas, inspiradas nos temas das grandes obras e simplificadas para a idade da criança, sem os temas delicados do original. Cada uma termina com a indicação do clássico para ler ou assistir quando crescer.

Qual a diferença entre box e coleção?

Um box é uma história com continuação: os volumes dependem um do outro e são lidos em ordem. Uma coleção reúne histórias do mesmo tema, que podem ser lidas em qualquer ordem.

Como as histórias são escolhidas?

Uma obra só entra no catálogo se valer a pena ser reencontrada mais tarde, e se tiver um valor ou uma jornada clara para apresentar à criança. Depois disso, o texto é adaptado para a idade e cada página é revisada.

Substitui os livros de alfabetização?

Não, complementa. Os livros de alfabetização treinam a decodificação. O GBM cuida da outra parte: a vontade de abrir um livro.

Como sei se meu filho entendeu a história?

Cada livro termina com um quiz de 5 a 10 perguntas. Para os menores, as respostas são desenhos, e o adulto lê as perguntas em voz alta. A última pergunta é aberta, para vocês conversarem sobre a história.

Posso baixar os livros?

Sim. Cada e-book também está disponível em PDF.

Quantos filhos posso cadastrar?

Todos. A assinatura é da família, e cada filho tem o seu perfil.
